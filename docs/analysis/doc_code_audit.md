| 数据入口 | README只介绍CSV与索引HDF5 | 训练/评估均有互斥的`motion_dir/index/source`三入口；补充合并源格式、名称、连续段边界及`motion_root`仅适用于索引 |

| 重复分箱与回合日志 | 全回合回报和课程评分容易混淆 | 同一步同箱的有效归一化评分先取均值再做一次EMA；训练奖励、回放及`ep_ret_norm`仍包含全部回合奖励 |
