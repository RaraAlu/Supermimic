## 0. 定位

SuperMimic是Dyna式的基于模型强化学习：从仿真数据拟合一个确定性、可微的世界模型，
再在世界模型里做短时域的一阶BPTT演员–评论家更新，思路接近SHAC。
核心论点是：所有参考动作共用同一套人形机器人动力学，
所以一个世界模型就能分摊整个动作库的学习成本（§1、§4.2）。

## 1. 问题设定：把随机性拆到模型外面

论文把每个随机来源都显式拆出，这是整个方法成立的前提（§3.1、§3.2）。

| 随机来源 | 处理方式 | 作用 |
| --- | --- | --- |
| 物理参数（摩擦、关节标定偏置、躯干质心） | 归入每回合的仿真上下文 $`\xi`$ ，作为世界模型输入 | 给定 $`\xi`$ 后动力学是确定的 |
| 传感器噪声 $`\eta`$ | 观测写成 $`o = \bar{o} + \eta`$ ；世界模型只预测无噪的 $`\bar{o}`$ ，想象推演时在模型外重新加回 $`\eta`$ | 策略对噪声鲁棒，世界模型不必学噪声 |
| 动作噪声 $`\epsilon \sim \mathcal{N}(0, 0.1^2)`$ | 只在真实仿真采样时加；缓冲区存加噪后实际执行的动作 | 扩大世界模型见过的动作范围；论文称其“可选” |
| 推力扰动 | 直接删除（附录A） | 确定性模型无法表示状态跳变 |

由此得到三个设计：

- 策略是确定性的， $`a = \pi(o, g)`$ ，没有熵项，也没有对数概率。
- 世界模型是确定性的， $`\hat{s}' = f(\hat{s}, a, \xi)`$ ，不需要随机潜变量或模型集成。
- 终止是软化的：存活权重 $`c_0 = 1`$ ， $`c_{t+1} = c_t (1 - d_{t+1})`$ ，回报 $`J = \mathbb{E}\left[ \sum_{t \ge 0} \gamma^t c_t r_{t+1} \right]`$ 。
  仿真记录硬终止，想象推演使用终止概率 $`\hat{d}_t \in [0, 1]`$ （本仓库由解析软终止函数计算），存活权重在想象推演中可导。

推断：这相当于把环境随机性换成已知分布的外生变量，是能用路径导数代替似然比估计的前提。
代价是方法无法处理世界模型看不到的随机扰动，推力鲁棒性只能靠critic补救（§4.3）。

## 2. 三阶段循环（算法A.1）的量化拆解

按表A.5，单卡每次迭代的工作量：

| 阶段 | 工作量 |
| --- | --- |
| ① 采样 | 4096环境 × 2.5步（更新数据比0.4）≈ 1.0万条真实转移 |
| ② 拟合世界模型 | 10批 × 2048窗口 × k=8步 = 16.4万次单步预测（10步或1步优化器更新，原文两读皆可，见[reset_sampling.md](reset_sampling.md)第7节） |
| ③ 策略更新 | 4096条推演 × H=32步 = 13.1万条想象转移，一次反向传播 |
| ③' critic | 13.1万条样本重复5轮，每轮拆4个小批（共20次优化器更新，非样本量再乘4） |

由此得到两个论文没有直接写出的比例：

1. 想象与真实数据之比约13:1。
2. 每条真实转移平均被世界模型重用约16次：每环境缓冲1000步、每次迭代进2.5步，
   一条转移约停留400次迭代；期间世界模型共抽样16.4万 × 400 ≈ 6,550万次，除以409.6万条转移约为16。

论文强调旧策略采到的数据对拟合世界模型仍然有效，因为动力学与采集策略无关（§3.1）。
世界模型部分完全离策略，策略梯度部分在想象中同策略计算，数据效率来自这种拆分。

## 3. 世界模型

### 3.1 结构与损失

```math
\begin{aligned}
\hat{s}_{t+1} &= f_\omega(\hat{s}_t,a_t,\xi), \\
\hat{r}_{t+1} &= r_\omega(\hat{s}_t,a_t,g_t), \\
\hat{\bar{o}}_t &= g_\omega(\hat{s}_t,\xi), \\
\hat{d}_t &= d_\omega(\hat{s}_t,g_t).
\end{aligned}
```

```math
\begin{aligned}
\mathcal{L}_{\mathrm{WM}}(\omega)
&= \mathbb{E}_{\mathcal{B}} \sum_{j=1}^{k} \Bigl[
   \lVert \hat{s}_j-s_j \rVert^2 + (\hat{r}_j-r_j)^2 \\
&\qquad + \lVert \hat{\bar{o}}_j-\bar{o}_j \rVert^2
   + \mathrm{BCE}(\hat{d}_j,d_j) \Bigr]
\end{aligned}
\tag{1}
```

窗口从记录的状态 $`\hat{s}_0 = s_0`$ 出发，按记录的动作自回归推进 $`k = 8`$ 步。

通俗地说：让世界模型拿自己的预测接着往下猜 $`k`$ 步，每一步猜出的状态、奖励、观测和终止都要和仿真记录一致；能用公式直接算的项不用学，也就不计损失。逐项拆解见[formulas.md](formulas.md)第5节。

每个预测头可以学习，也可以解析计算；解析头不计损失。

### 3.2 三个要点

**(1) 动力学网络不接收目标 $`g`$ 。**
$`f_\omega`$ 的输入只有 $`(\hat{s}, a, \xi)`$ ，只有奖励头和终止头依赖 $`g`$ 。
这正是“一个模型分摊整个动作库”的机制：动作库变大，带来的是同一套身体与接触动力学的更多样本，
而不是对新模型容量的需求。图3(c)中数据从1 h扩到264 h，8步误差始终在0.007–0.011，是直接证据。

**(2) 多步自回归损失让模型学会纠正自己的误差。**
单步损失只约束真实状态上的预测；k步损失让模型在自己预测出的、略有偏差的状态上也受监督，
相当于一种去偏的数据增强。论文据此称模型在H=32（大于k=8）乃至“无限长”推演中都保持稳定（§3.3），
但没有给出定量证据，属于经验观察。

**(3) BPTT需要雅可比准确，而不只是预测值准确。**
策略梯度取决于 $`\partial f / \partial \hat{s}`$ 和 $`\partial f / \partial a`$ 。式(1)只监督预测值；雅可比是否准确，取决于数据在当前策略动作附近的覆盖。
推断：0.1的动作噪声正是在这里起作用，它在策略动作周围提供局部激励，让模型对 $`a`$ 的导数有数据支撑。
论文只说它“扩大拟合范围、可选”，没有从梯度质量角度讨论，也没有去掉噪声的消融。

### 3.3 论文未给出的部分

状态 $`s`$ 包含哪些量、哪些头是学习的、输入输出如何归一化、网络输出绝对状态还是增量，论文都未说明。
本仓库的选择可作为一种可行解（实现细节按`4b4d27a`核对）：

- 输入用与朝向和水平位置无关的不变特征；
- 输出用局部坐标系下的增量；
- 奖励、观测、终止三个头都用解析式，终止用sigmoid平滑；
- 先跑500次只拟合世界模型的预热迭代。

这是训练入口默认值；双卡短测用`--wm_only_iters 0`，不能把实验配置视为默认行为。
现行重置采样另有论文未规定的过渡期与末尾限制：默认跳过前50步评分、段末100步不起步，
短片段首帧只分均匀份额，详见[training_pipeline.md](training_pipeline.md)第3–4节。

## 4. 策略优化：短时域一阶梯度

### 4.1 目标函数与梯度路径

```math
\begin{aligned}
\hat{J}(\theta)
&= \mathbb{E}_{s_0\sim\rho_0} \Bigl[
   \sum_{t=0}^{H-1} \gamma^t \hat{c}_t \hat{r}_{t+1} \\
&\qquad + \gamma^H \hat{c}_H
   V_\psi(\hat{s}_H,g_H,\xi) \Bigr]
\end{aligned}
\tag{2}
```

```math
a_t = \pi_\theta(\hat{\bar{o}}_t + \eta_t, g_t), \quad \eta_t \sim \rho_\eta
```

通俗地说：在世界模型里“做梦” $`H`$ 步，把这 $`H`$ 步拿到的分加起来（越可能摔倒，后面的分打折越多），再加上critic估计的“ $`H`$ 步以后还能拿多少分”。按满分估算，后一部分约占目标的73%，所以critic不可或缺（[formulas.md](formulas.md)第6.2节）。

起点从缓冲区抽样，带着真实的 $`\xi`$ 和真实状态分布。梯度沿两条路径流动：

- 动作路径： $`\theta \to a_t \to \hat{s}_{t+1} \to`$ 之后所有奖励；
- 闭环感知路径： $`\hat{s}_t \to \hat{\bar{o}}_t \to \pi_\theta \to a_t`$ 。策略“看到的”状态也随 $`\theta`$ 变化，梯度要穿过观测头；
  观测头为解析式时这条路径是精确的。

梯度中有雅可比沿时间的连乘，这是一阶方法的根本矛盾：

```math
\prod_{t} \left( \frac{\partial f}{\partial \hat{s}} + \frac{\partial f}{\partial a} \frac{\partial \pi}{\partial o} \frac{\partial g}{\partial \hat{s}} \right)
```

通俗地说：每多想象一步，梯度就要多乘一个这样的因子。它略大于1，梯度就会爆炸（ $`1.1^{32} \approx 21`$ ）；
略小于1，远处的影响几乎消失（ $`0.9^{32} \approx 0.034`$ ）。两步情形的完整链式法则见[formulas.md](formulas.md)第6.3–6.4节。


| 时域 | 后果 |
| --- | --- |
| H太短 | 看不到截断之后的后果，策略短视（无critic时H≤16失败） |
| H太长 | 雅可比连乘导致梯度爆炸或混沌，模型偏差累积；显存线性增长（H=128是H100上限） |

图4(b)(c)正是这个U形：H=32最快达到0.82；H从64增至128，耗时近三倍，最终回报反而下降。

### 4.2 一阶梯度为什么比PPO高效

论文的论证是方差：PPO用 $`\nabla_\theta \log \pi_\theta`$ 乘优势，是似然比估计，方差随动作维度（29）和时域增长；
BPTT直接对每个动作求导，是路径导数估计，短时域内方差低得多（§3.3）。

图5(b)把这一点与推演速度分开：在同一个世界模型里跑PPO（PPO-WM），
SuperMimic用少约64倍的想象步数就达到PPO-WM的最佳回报。
模型和推演速度相同，差异只来自梯度估计方式，这是全文最干净的机制消融。

推断：学到的世界模型是接触动力学的平滑近似，这可能反而是优势。
真实仿真在接触处不连续，直接对它求导梯度很差；神经网络天然给出平滑雅可比，类似随机平滑。
这也解释了论文为何强调“不需要可微仿真器”。代价是梯度属于代理目标，
论文自己也承认这是“对仿真中期望回报的代理的梯度”（§3.2）。

### 4.3 稳定性措施

| 措施 | 作用 |
| --- | --- |
| 梯度先按全局范数1.0裁剪，再逐元素按0.1裁剪 | 说明BPTT梯度有偶发尖峰 |
| 策略Adam用 $`\beta = (0.9, 0.95)`$ | 较短的二阶矩记忆，适应世界模型持续变化带来的非平稳梯度 |
| 世界模型与策略每次迭代都更新，比例1:1 | 模型漏洞刚被策略利用，就会被新数据修正 |
| 确定性策略加想象中的传感器噪声 | 噪声注入代替熵正则，起平滑作用 |

## 5. Critic：从短时域走向长期目标

```math
\begin{aligned}
\mathcal{L}_V(\psi)
&= \mathbb{E}\sum_{t=0}^{H-1}(V_t-\hat{R}_t)^2, \\
\hat{R}_t
&= \hat{r}_{t+1}+\gamma(1-\hat{d}_{t+1}) \\
&\qquad\cdot\bigl[(1-\lambda)V_{t+1}
   +\lambda\hat{R}_{t+1}\bigr], \\
\hat{R}_H &= V_H.
\end{aligned}
\tag{3}
```

其中 $`V_t = V_\psi(\hat{s}_t, g_t, \xi)`$ 。

通俗地说：critic的训练目标是“这一步的分 + 之后的估分”。“之后的估分”在critic自己的估计和后面实际想象到的分之间按 $`\lambda`$ 混合：$`\lambda = 0`$ 时只信自己，偏差大； $`\lambda = 1`$ 时只信想象的结果，方差大（[formulas.md](formulas.md)第7节）。

- 只在想象转移上训练；GAE目标每次推演算一次后固定；没有指数滑动平均的目标网络。
  这与SHAC不同，SHAC是硬终止且有目标网络。
- critic输入 $`(\hat{s}, g, \xi)`$ 含特权信息 $`\xi`$ ，而策略只看带噪观测，属于非对称演员–评论家。
- critic的作用不只是加速。§4.3指出，回报相当时，有critic的策略在推力后0.5–2.4 s内恢复，
  无critic的策略始终稳不住：恢复平衡的收益在32步之外，只有自举值函数能把它传回当前。
  在确定性世界模型删掉推力之后，这是推力鲁棒性的唯一来源。

## 6. 超过1000倍加速的来源

| 来源 | 证据 | 量级 |
| --- | --- | --- |
| 推演吞吐 | 图5(a)：世界模型对比MuJoCo Warp | 2k–16k环境超过10倍；64k环境62倍 |
| 梯度效率 | 图5(b)：一阶梯度对比同一世界模型里的PPO | 想象步数少约64倍 |
| 分摊 | 图3(b)(c)：数据增大，世界模型误差不变 | 达到目标回报的耗时增长缓慢 |
| 课程采样 | 附录D.1：按回报重置 | 无消融；本实现发现分箱细节会让课程跑偏，见[reset_sampling.md](reset_sampling.md) |
| 混杂因素（论文自认） | 数据少2.3倍（264 h对611 h）；H100张量核峰值为L40的5.5倍 | 合起来不足以解释1000倍 |

比较口径需要注意（附录F）：

1. 基准就是训练集：129,514段全是训练动作，比的是覆盖程度，不是泛化，论文自己也说明了。
2. 失败判据用SuperMimic自己的终止条件（含倾斜项）。SONIC自己的判据只看根和末端高度偏差，无朝向项。
   用SuperMimic的判据评SONIC未必公平，方向上可能偏向SuperMimic，论文未量化。
3. 3 h的取法较保守：从3 h起每个检查点的回报和失败数都领先SONIC，
   且领先幅度至少是“SONIC与SuperMimic最佳结果之差”的一半。
4. 未报告种子方差：论文只说“多个种子都很稳定”，归因于动作追踪的稠密奖励。

## 7. 多接口扩展（附录B）

- 一个共享解码器 $`\mathrm{dec}(z, o)`$ ，每种目标接口一个编码器 $`\mathrm{enc}_i(g) \to z`$ ，所有接口共用同一个世界模型，不重新训练。
- 下游接口（如速度指令）的梯度在解码器处截断，解码器只由动作追踪目标训练。
  速度编码器另有权重0.1的潜空间对齐损失，拉向动作编码器的潜变量。
- 结果：用自身奖励做RL训练的编码器在672次阶跃测试中有650次误差更低，中位相对误差0.16对0.49。
- 论文自认的局限（§6）：奖励不更新解码器时，“联合训练”等价于先训追踪器再训编码器；两个方案各只有一个种子。

推断：这套结构的价值在于，任何新接口都能直接在已学好的动力学里用自己的奖励做RL，不必依赖蒸馏。
对应表1，SuperMimic是唯一一个模仿、潜空间、下游三阶段都用同一套基于模型强化学习、并且上过实机的方法。

## 8. 隐含假设与风险

1. **模型被策略利用。** 一阶梯度优化很容易钻世界模型误差的空子。论文没有讨论，
   也没有用集成或不确定性惩罚（RWM-U用了），依赖的是持续用自身数据重新拟合加短时域。
   复现时应监控同一批状态上想象回报与仿真回报的差距。
2. **只有平地、只用仿真数据。** 没有地形和物体交互，也没有真实机器人数据（§6）。
3. **删除自碰撞惩罚。** 理由是确定性策略无法利用这个漏洞（附录A），但论文没说仿真器本身是否开启自碰撞。
   本仓库默认开启自碰撞，参考实现关闭，两者的评估结果不能直接对比。
4. **规模结论只有一条曲线。** 数据规模扫描只有1、7、40、264 h四个点，没有方差；“名义误差”未定义。

## 9. 对复现的影响

### 9.1 建议监控的指标

- 世界模型窗口末步误差（日志名固定为`wm_err8`，默认窗口8步）；它按单步增量标准差归一化，不能直接与图3(c)未知的标称尺度比较；
- 想象推演存活率，以及策略梯度在裁剪前的范数；
- 同一批起点上想象回报与仿真回报的差距，用于发现模型被利用；
- 时域与critic消融（论文图4(b)(c)），这是成本最低的验证实验。
